# Documentação de Game Design

Este diretório registra as decisões de game design aprovadas para o projeto. Ele não contém arquitetura técnica, escolhas de engine, rede, banco de dados ou implementação.

## Estado da fase atual

- Fase encerrada em 1 de outubro de 2026.
- Etapas concluídas: fundação do cenário, elenco jogável, sistemas centrais e estrutura das dez regiões da masmorra.
- Etapa atual: arquitetura técnica e prova de viabilidade do MVP.
- Arquitetura técnica: autorizada pela declaração formal do responsável pelo projeto.
- Revisão posterior aprovada: cooperativo online com host e combate de hordas com movimento por mouse.

A transição técnica só poderá começar após a frase:

> A fase de game design está encerrada. Podemos começar a arquitetura técnica.

## Convenções

- **Definido:** decisão aprovada e vigente.
- **Em discussão:** assunto atualmente em elaboração.
- **Não definido:** assunto propositalmente aberto ou ainda não discutido.
- Uma sugestão não altera uma decisão existente até ser aprovada.
- Conflitos com decisões existentes devem ser apontados antes de qualquer alteração.

## Identidade resumida

O jogo é um roguelike RPG geracional cooperativo online em pixel art para um a quatro jogadores. Um participante hospeda o mundo e os demais entram em sua sessão. Dez personagens autorais formam a primeira geração de uma pequena vila e exploram uma masmorra de cem andares. Mortes parciais permitem reencarnação; a morte de todo o grupo avança o mundo para uma nova geração. O progresso individual fortalece famílias; as famílias desenvolvem serviços; os serviços transformam a vila; e a vila preserva seu legado entre gerações.

O contraste central é:

> Vila = casa, comunidade, memória e consequência.
>
> Masmorra = desconhecido, oportunidade, perigo e transformação.
